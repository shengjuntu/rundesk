# RunDesk 0.25.0 / Kun 0.6.0

本版继续按 Kun 开发计划完善检查能力：将请求/结果关联成调用证据，直接阅读模型实际输入，比较两份固定快照。所有新查询只读，复用原有授权，不产生模型或工具调用。

- Network 展示模型、工具、MCP 的关联证据、结果缺失、耗时与已报告用量。固定请求快照不会混入后来的回答。
- Elements 显示有序消息、技能来源与工具定义；区分实际请求和状态上下文，原始 JSON 折叠保留。
- 快照差异显示两端运行/版本，先脱敏再比较，大整数精度保留，内容/路径/变化数量有界并标记截断。
- 刷新增量读取并限制客户端缓存；保留展开与滚动状态；修复 Performance 历史时点展示未来事件。
- 新增重启后精确查询、只读/授权、差异边界和前端关联/异步响应回归；已有条件断点与安全恢复测试继续通过。

RunDesk 和 Kun 必须同步更新：worker 协议 v6。已有快照可读取，旧版本检查点不跨版本续跑。源码包不含编译产物；使用 Go 1.25.12+ 执行 `make build` 构建两个程序。

本地 fixture 全量测试、所选竞态测试、静态检查、前端逻辑测试、Linux 构建与 Windows 交叉构建通过。无 Chromium，更新后的浏览器场景未执行；真实模型/MCP、Windows 实机及生产业务尚未验收。K2 不标记全部完成。

参见 [检查说明](KUN-INSPECT.md)、[计划完成度](KUN-PROGRESS.md)、[验证记录](KUN-VALIDATION.md)。
