# RunDesk 0.40.0

本版完成 K4 优化实验的基础实现：从固定成功案例提炼参数化 Skill，经独立验证集全部通过后启用到指定应用，使用受限快速路径执行，并在守卫偏离时保留已完成结果回到动态循环。

## 主要变化

- 固定案例：完整有效输入、环境与唯一 run/session 绑定；明确启动、幂等重试、运行记录、逐案例评分，删除墓碑防止旧预览复活。
- Skill 候选：保存成功来源、输入与事件指纹、适用范围、失败条件；自动参数化工具调用，也可提交受限 IR 草稿；不复制常量答案或失败轨迹规则。
- 独立验证：至少两个不同输入，与来源隔离；固定候选和验证批次；汇总每例完整回复/事件证据，缺失保留未知。仅评分全部通过且快路径真正完成的候选可启用。
- 快路径：tool/extract/assert/branch/finish 五种指令，前向分支和有界 Schema；输入、领域、工具版本、权限、Skill、环境与中间断言守卫。
- 回退：复用原审批、预算、动作账本和工具网关；不重启已经完成的动作。动态阶段重复请求相同已成功写入/MCP 调用时复用已记录结果并记录 reusedFrom。
- 应用范围：管理员选择同实例/工作区的指定应用与 revision 启用；应用通过 Input.fastSkillId 显式选择；可停用，不修改全局 Skill 文件。
- 工作台：任务集下直接生成/执行案例预览；独立 K4 Skill 工作台可创建候选、读取历史批次、执行/评分、启用/停用；回复、导出与轨迹支持快路径事件。

## 升级

RunDesk 0.40.0，Kun 0.13.0，worker 协议 13，fork schema 3。两个二进制一起更新。历史日志仍可检查；旧引擎的执行预览和检查点不跨版本运行，请重新生成。新增 16 个管理 API 操作，总计 173 paths / 208 operations；无新增运行时依赖。

## 验收范围

当前精确测试结果和日志见 [KUN-VALIDATION.md](KUN-VALIDATION.md)。核心端到端使用真实本地宿主/worker 和本地 HTTP 模型夹具；Go 覆盖审批与回退，Node DOM 覆盖工作台交互。保留首轮失败记录与修复后发布回归，不能将首轮失败隐藏为通过。

本版不包含可选学习型 JEV、任意脚本编译器或统计显著的通用性能结论。真实浏览器布局、远程模型/MCP、业务任务集、生产负载和 Windows 运行尚未验收。使用方法和准确边界见 [KUN-K4.md](KUN-K4.md)。
