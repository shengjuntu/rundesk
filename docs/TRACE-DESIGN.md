# 轨迹工作台：设计记录

v0.5.0 已实现首版，使用 Go + 原生 HTML/JS，无新增运行依赖。完整操作见 [轨迹工作台](TRACE.md)。

设计延续 Audio Data Toolkit 的总览、缩放、分层轨道、联动详情、固定导航和专注模式。深色轨道区提供清晰的区间对比；外围采用浅色管理界面。选中事件用边框和同步定位线表示，其他内容保持可读。

## 已实现

- 全程总览与可拖动、缩放的视窗；主轨道滚轮缩放与拖动平移。
- 输入/回复、可见模型阶段、工具、审批、上下文注入、状态六类轨道，可分别隐藏。
- 时间比例与等距步骤两种模式，明确区分语义；密集轨道提示剩余数量。
- 可读详情、结构化数据和完整原始记录入口；大 JSON 限制显示长度并提供完整下载。
- 运行、类别、文本和异常筛选；步骤/异常导航，键盘操作，专注模式与窄屏抽屉。
- 生命周期游标分页、虚拟步骤列表、增量更新、稳定选择和刷新恢复。
- 缺失端点标识、审批区间并集、线程累计 Token 与上下文占用区别。

## 当前边界与后续工作

- 模型阶段仅来自公开 item，不提供无法验证的模型请求耗时、TTFT 或隐藏推理。
- 原生记忆与技能自动使用仅在有明确事件时才可展示；首版保留显式 Skills 和项目笔记注入。
- 尚无独立 turn/status 下拉组合查询、跨会话对比、服务端全轨迹索引、火焰图和断点调试。
- 未提供完整模型 HTTP 请求、系统提示快照和上下文占用曲线；需要先确认原生接口的数据来源。
- 首版使用点击选择并自动定位，不需要双击。业务可视化继续放在 ActiveVLM 等上层应用。
