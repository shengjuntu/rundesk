# 验证资料的保留规则

当前源码只保留本说明与[本版验证摘要](current/release-073.json)。可复现的检查入口、输出位置和验收边界见[验证与复验](../VALIDATION.md)。

## 历史资料

0.65.0 及更早版本的原始验证 JSON、JSONL、日志、截图、测试视频和整理记录完整保留在此前交付的 `rundesk-v0.65.0-source.zip` 中；该源码包的 SHA-256 为：

```text
6b889209f4726bf4de79b9a04814064a0b9edfb684072ebfd6ad7e753f955122
```

历史文件继续保持原版本、路径、执行环境和测试范围，不改名为当前结果，也不继承为本版通过数。当前源码不再重复携带它们或再嵌套一份历史 ZIP。需要追溯旧结果时，使用上述完整旧源码包核对摘要后查阅。

## 新结果

本版发布摘要记录实际执行的检查、结果、跳过和未覆盖范围。脚本生成的可再生报告、日志和截图默认进入 `build/qa/<检查名称>/`，也可通过其输出参数写入源码目录之外；不回写本目录。临时结果不得携带真实凭据或被误认为产品资源。

后续版本沿用相同规则：发布源码保留当前摘要，完整旧版本保留原始证据；清理源码不触及 RunDesk 用户数据目录中的任务、构建快照、修复经验或认证。
