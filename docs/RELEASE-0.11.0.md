# RunDesk 0.11.0

本版实现多用户应用协作的第一阶段：管理员管理运行环境，成员只进入被分配的应用项目。新增用户与授权页、个人访问码和独立成员工作台，支持查看执行过程、复制回复、上传、下载与常见命令/文件审批。

项目按只读或可执行授权。服务端拦截跨项目访问、管理员接口访问和只读写入；账号停用及授权变更使旧登录失效。管理员通用助手仍使用本机 Codex，成员应用使用 Docker。

详见 [操作与权限说明](USERS.md) 和 [本版验证](VALIDATION-0.11.0.md)。内置 Docker 镜像构建任务继续作为 0.12 的目标；当前镜像页面登记与选择外部构建的镜像。

交付包括源码、Linux amd64 和 Windows amd64 二进制。Docker 执行仍仅支持 Linux 本机 daemon。Windows 二进制只做交叉编译；真实 Docker、真实 Codex 模型以及远程部署需要实机验收。

恢复说明：本次取回的上一版 ZIP 缺少尾部目录。已逐文件校验 CRC 与长度，恢复 463 个完整条目，生产源码与 Go 测试均在其中。部分旧浏览器脚本不在可恢复范围；保留旧报告只作为历史记录，不视为本次重新验收。新增的用户验收及本版列出的回归脚本随包交付。详见 SOURCE-RECOVERY.md。
