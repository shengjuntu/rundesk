# RunDesk 0.9.2 — 应用 API 凭据（重建版）

在 0.9.1 上增加应用专用凭据和服务器端资源授权。权限固定绑定应用、专用配置和项目，支持有效期、撤销和单次显示。API 仍为 /api/v1，契约版本 1.7.0；新增 GET /whoami。既有管理员接口兼容，应用凭据默认拒绝配置接口。

幂等回执按凭据隔离，防止跨应用读取或重放。鉴权在回执回放之前检查；显式 Bearer 不继承 Cookie 权限；旧 API 同样保护。凭据撤销/过期会关闭对应 SSE，已接受任务/规则需单独停止。

应用详情页新增凭据管理。Python SDK 增加队列、定时和身份接口；提供应用接入、权限边界和升级文档。这是应用 API 授权，不声称完整多用户或操作系统隔离。无需容器。
