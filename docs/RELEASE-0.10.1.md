# RunDesk 0.10.1 — 应用镜像版本管理

应用页增加镜像摘要，详细配置独立放在「镜像与构建」。可以登记本机镜像，查看构建者提供的来源、版本和能力信息，并明确选择哪些环境升级。

- 登记镜像保存固定 Image ID、仓库 Digest、平台、大小和元数据；相同标签指向新镜像时保留为新版本。
- 镜像列表显示应用目标、使用环境数、上次可用性检查和失败详情；缺失信息明确显示未提供。
- 选择应用版本只改变新环境目标；已有环境继续使用原镜像与资源，显示待更新状态。
- 按环境显式更新，先检查目标镜像，再停止旧容器；环境和应用双 revision 防止页面过期后更新到意外目标。
- 宿主机项目、认证、Skills、MCP 配置与历史保留；旧版本可重新选用，不自动回退文件。
- 新增管理员镜像 API、OpenAPI 1.9.0、镜像标签约定和 Dockerfile 示例。

升级：替换程序并保留原数据目录。0.10.0 的应用、会话和环境无需迁移，不会自动登记或选择镜像，也不会自动重建。0.10.0 在目标配置变化后阻止旧环境新连接；0.10.1 改为旧环境继续沿用自己的快照，显式更新后才采用新配置。

范围：本版管理命令行、CI 构建或手动拉取的本机镜像；没有内置构建/拉取队列。Docker 仍仅支持 Linux 本机；完整多用户、远程 Docker、Windows/macOS Docker 路径映射未加入。真实 Docker、镜像构建及付费模型联调仍需在部署主机验收。

详见 [镜像与构建信息](IMAGES.md)、[Docker 使用](DOCKER-ENVIRONMENTS.md)、[验证记录](VALIDATION-0.10.1.md)。
