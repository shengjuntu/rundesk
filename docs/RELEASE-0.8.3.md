# RunDesk 0.8.3

本版根据 HTTP 500 排查修复连接阻塞、失败连接清理、无效任务确认和不完整回执问题。原有「错误记录」界面、单轴 Turn 时间线和独立分析会话保留。

- 调用超时覆盖向 Codex 写数据的阶段；已取消调用不再发送。
- 超长 stderr 不阻断进程；损坏 JSON 快速失败，保留退出原因。
- 初始化失败与坏的配置连接清理后，下次显式操作重新建连。
- 未取得有效 turn.id 时明确提示提交不确定；事件记录失效或任务输入落盘失败时，不启动新的 Codex 任务。
- v1 明确区分上游 502、不可用 503 和超时 504，保留原始错误和请求编号。真正的内部 500 继续呈现。
- 回执内容校验避免损坏状态触发 panic；重放仍不重复执行。

没有自动重复发起任务或配置写入。外部 provider/代理的 500 仍需根据实际诊断处理，不能承诺“以后不会出现任何 500”。本次没有定位用户当次故障的根因。

停止旧服务并替换程序，保持数据目录、CODEX_HOME 和启动参数，刷新浏览器即可；无需数据迁移。提供 Linux amd64 和 Windows amd64 可执行文件，Windows 仅交叉编译。
