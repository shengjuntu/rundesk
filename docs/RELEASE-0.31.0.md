# RunDesk 0.31.0 / Kun 0.7.0

本版开始 K3-A：管理员可冻结 Kun 单个轮次的记录，建立离线实验基线，通过假设工具返回文本创建不可变子分支，查看谱系、逐条记录和差异。

- 来源固定到明确轮次和宿主事件上界；脱敏副本独立持久化。新来源事件、宿主重启和原会话删除不会改变已有实验。
- 每次编辑或恢复新建子分支；原始 JSON、父分支、来源状态及外部文件保持不变。最早编辑点之后的记录保守标记为后续未验证。
- 新增管理员专用、默认拒绝其他凭据的有界 API 和界面。写入支持 HTTP 幂等重试，异步旧响应不会覆盖新选中的分支。
- 记录编辑回放不调用模型、工具或 worker，不重新生成后续答案；没有运行时检查点分叉、Hybrid、Live 或 K4 优化。
- 实验副本不会随来源会话删除；当前没有实验删除/过期接口，留存与脱敏边界见使用说明。

Kun 引擎保持 0.7.0 / 协议 v7，worker `fork=false`；离线记录分支属于宿主能力。0.30.0 升级到本版不改变引擎检查点兼容标识。使用 Go 1.25.12+ 执行 `make build`，同时交付 RunDesk 和 Kun。无新增第三方运行时依赖，源码包不含二进制。

全量 Go、专项竞态、静态检查、Linux/Windows 构建和五组本地 Chromium 流程通过。模型/MCP 使用本地 fixture，Codex 使用协议 DEMO；未进行真实服务或生产环境验收。

见 [离线实验说明](KUN-EXPERIMENTS.md)、[验证记录](KUN-VALIDATION.md) 和 [开发完成度](KUN-PROGRESS.md)。
