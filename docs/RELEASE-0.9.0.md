# RunDesk 0.9.0 — 持久化任务队列（重建版）

从已恢复的 0.8.4 源码重建，不是原先丢失 ZIP 的逐字节副本。

- 新增任务页：提交、过滤、查看过程、取消、暂停与并发管理。
- 新增 /tasks、/queue API；沿用 HTTP 幂等提交回执。
- 交互任务与队列共享并发额度，等待审批计入运行中。
- 重启不自动重复执行不确定任务，任务会话与入队事务保存。
- 直接调用本机 Codex app-server，不使用容器。

替换程序前停止旧服务并备份数据目录；继续使用原 --data。数据库只增加对象类别，不改变已有会话格式。保留旧二进制和备份；不要同时运行新旧版本。新版尚有队列任务时，不应直接降级到不了解队列的旧程序。
