# RunDesk 0.6.1 — 对话交互

这一版让对话内容更容易阅读和操作，延续 0.6.0 的 API 与实例配置设计。

## 使用变化

- 命令、推理摘要、文件修改、MCP、搜索等工具卡片用 SVG 图标区分。收起时显示命令、工具名或已有摘要中的简短内容，不再重复类型名称和展开箭头。悬停可查看类型和状态，键盘仍能展开详情及原始数据。
- 已完成的模型回复下方有复制、有帮助、有待改进、分享、朗读。流式回复完成后才显示这组操作。
- 复制回复保留原始 Markdown；代码块可单独复制。剪贴板被浏览器拒绝时显示可选中的文本，供手动复制。
- 评价保存到后台，刷新或重启后保留。负面评价可补充原因，保存后可通过说明图标查看和修改，再次点击已选评价可取消。评价不自动发送给模型服务。
- 分享先预览选中回复，再复制、下载 Markdown 或使用受支持设备的系统分享。生成的文件只包含该回复，不带会话输入、工具日志、配置或访问令牌；原文自己包含的内容仍会原样保留。没有公开分享链接。
- 朗读正文时跳过代码块，可暂停、继续和停止；长正文按段分批播放。切换会话、新建对话或离开页面会取消朗读。浏览器不支持时禁用按钮，语音失败会显示提示。实际语音与暂停行为取决于浏览器和操作系统。
- 对话区、输入区和工具卡片统一了间距与阅读宽度。手机使用完整宽度，通过顶部菜单打开历史会话、实例和工作区抽屉。

图标均保留可访问名称，主要按钮支持键盘焦点。运行中的工具状态尊重系统“减少动态效果”设置。

## 应用 API

新增已完成回复读取、会话评价列表和评价写入三个端点。OpenAPI 文档版本为 1.1.0，共 42 个路径、49 个操作。路径仍为 `/api/v1`，0.6.0 的提交去重、状态、来源标签、实例配置接口保持原有含义。详见 [API-V1.md](API-V1.md)。

## 升级

停止旧后台后，使用新可执行文件和原来的 `--data` 目录启动。新增评价复用现有数据库的对象存储，不替换原事件日志、会话或实例。使用 0.6.0 与本版实际 Linux 可执行文件做了升级回归；历史会话可继续使用原生 thread，详见 [VALIDATION-0.6.1.md](VALIDATION-0.6.1.md)。

ZIP 包含源码、文档、测试脚本以及 Linux/Windows x86-64 可执行文件。Windows 文件为交叉编译产物。本次使用 Codex 协议模拟器验证运行流程，没有使用真实模型凭据；朗读与系统分享控制通过浏览器接口替身验证，尚未做有声设备和 Windows 实机验收。

## 范围

本次没有修改轨迹视图和轨迹模型。轨迹的独立重设计仍留作后续议题；Video App 的制作链路也未加入本版。

## 浏览器接口参考

- [MDN：Web Share](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share) — 系统分享需要受支持的安全上下文和用户点击。
- [MDN：SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis) — 朗读、暂停、继续和取消。
