0.35.0 的增量是 **K3-C 的运行中安全组合切换首批**，不代表任意模块热替换或完整 K3 验收。仅管理员可在普通运行 before_model 已暂停、没有待处理工具/审批/控制时切换两套内置组合；清除旧计划，保留权限、历史和累计预算，应用后仍暂停。切换后的状态可恢复和分叉，普通新轮次回到默认组合。范围见 [KUN-HARNESS.md](KUN-HARNESS.md)，验证见 [KUN-VALIDATION.md](KUN-VALIDATION.md)。

0.36.0 的增量是 **K3 跨会话描述性对照首批**：只读宿主记录，固定两侧游标，不启动 worker 或调用模型；只接受同一不可变基线，缺失证据时不计算相关差值。不是任意会话对照、同条件评测、自动优化或 K4。说明见 [KUN-COMPARISON.md](KUN-COMPARISON.md)。

0.37.0 的增量是 **K3 工具结果假设与 Hybrid 重算首批**：只从权威私有录制派生一个固定替换，不导入 K3-A 的脱敏覆盖值。原状态/参数/预算保持，运行证据区分人工假设；不是完整依赖图、任意嵌套实验或 K4。范围见 [KUN-HYPOTHESES.md](KUN-HYPOTHESES.md)。

0.38.0 的增量是 **K3 固定规则评分首批**：规则绑定同基线，按固定日志范围中的完整最终回复匹配，未知不按零，报告独立保存。规则可事后制定，尚无预注册、独立验证集、产物/事实验证或自动优化，不能以高分认定 K4 达标。说明见 [KUN-EVALUATION.md](KUN-EVALUATION.md)。

0.38.1 补齐评分版本的最终本地回归，并加入可重复执行、逐项保存日志和 JSON 状态的验证入口。此次没有新增业务功能，不改变 K3/K4 的阶段边界。

0.39.0 新增 **固定输入任务集定义首批**：1–20 个有序案例，固定输入与文本规则、不可变保存、分页查看与复制为新草稿。仅完成定义层，尚无批量执行、逐案例运行/结果绑定、汇总评分或独立验证集隔离。说明见 [KUN-TASK-SETS.md](KUN-TASK-SETS.md)。

0.40.0 完成 **K4 基础闭环**：从成功案例自动参数化工具轨迹，保存有来源/适用范围/失败条件的候选；使用预先固定的独立任务集逐例执行和汇总，全部通过才可启用到指定应用。快速路径经现有审批和账本，守卫偏离保留位置与已完成结果回退；重复相同副作用复用记录。详情见 [K4 使用与边界](KUN-K4.md)。上文各版本段落保留当时范围，不代表当前仍未实现。

0.41.0 完成 **K4 多次采样描述性对照首批**：固定验证案例在动态/快速两组重复执行，保存样本与配对证据；一次确认覆盖整批，沿用并发/审批，停止和中断不重放。指标显示缺失范围，报告不能替代独立验证门槛。不包含业务数据收集、随机化、统计显著性、工作区隔离或费用核算。详情见 [多次采样对照](KUN-BENCHMARKS.md)。

0.42.0 完成 **K4 产物规则首批**：在固定案例中预先定义工作区文件存在、文本包含/相等或 SHA-256，worker 将完成时观察与结束事件事务保存；后续文件修改不改历史。缺失、不完整、超限或读取错误为未知；错误或缺失文件阻断来源和独立晋升，重复对照也计入。每案例最多 8 条，每文件最多 1 MiB；不证明文件新建，不验证事实或外部系统，不隔离并发写入。详情见 [产物规则](KUN-ARTIFACTS.md)。协议升至 14，Kun 0.14；旧报告仍可读，跨版本执行需重建预览和候选。

0.43.0 完成 **K4 独立评测目录首批**：每案例可预先固定 0–16 个输入文件，每次动态、快速和独立验证从新目录初始化；已有目录拒绝覆盖或重置，预览无文件操作。初始化证据与运行绑定，缺失保持未知；重启/继续跳过已完成身份，回退沿用原目录。该模式只支持内置文件工具，候选绑定目录模式且不可直接晋升共享应用。协议升至 15，Kun 0.15；范围见 [独立评测目录](KUN-FIXTURES.md)。这不等于 OS/网络隔离或完整 K4 业务验收。

0.44.0 完成 **PiG 七类核心编程工具首批对齐**，包括宿主 Bash 与审批、精确编辑、grep/find；生成 Python 程序实际执行与 K4 回退不重复副作用已有本地证据。更正完成度口径：原 K1“基本完成”仅适用于最小运行/检查闭环，不能等同完整编程 Agent 或 PiG 全能力。K4 基础闭环已可测试，但不代表隔离执行或业务收益已经验收。功能差距和下一批验收见 [PiG 对照](KUN-PIG-CORE.md)。
