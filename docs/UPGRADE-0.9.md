# 0.8.4 → 0.9.x 重建版升级

三个包均从恢复的 0.8.4 重建，包含源码、测试、文档、Linux amd64 与 Windows amd64 二进制，不是丢失下载包的逐字节复原。

1. 停止现有 RunDesk，备份整个 --data 目录和旧二进制。
2. 解压最新版 0.9.2，使用原 --data、--listen、--codex、管理员 Token 配置启动；无需依次安装 0.9.0、0.9.1。
3. 通用助手、应用绑定、Skills/MCP、历史会话继续使用原数据；不要同时开两个服务写同一数据目录。
4. 「任务」页设并发，创建普通或定时任务；「应用」页为应用签发凭据。
5. news2douyin / video app 的后端改用专用凭据和 /api/v1；原管理员 Token 接入仍兼容。应用注册/修改能力保留在管理员安装流程，不由应用凭据调用。

排队任务、Cron、凭据只是 SQLite 新对象类别。完整备份可供回滚；存在新任务和规则时不要让旧版写同一数据目录，因为旧版不了解它们。

版本分工：0.9.0 队列；0.9.1 增加 Cron；0.9.2 增加应用凭据与 API 授权。宿主机原生执行，不引入容器或额外 agent loop。

仍未实现：完整多用户账户/RBAC/操作系统级隔离、原生历史批量导入、全量原生记忆管理、任意 MCP 工具的独立测试工作台、完整富文本编辑器、分布式调度。
