# RunDesk 0.44.0

补齐 Kun 的 PiG 核心编程工具，遵守选择性参考和独立发展的既定方向。Kun 升至 0.16.0，worker 协议升至 16，fork schema 保持 3。

- 新增可选 Bash：独立宿主权限授权、持久审批、超时/取消、普通子进程清理、有限输出与退出状态；支持运行生成的代码及构建/测试命令。
- 新增精确多处编辑、grep 和 find，与已有读写和目录工具组成七类核心动作。文件工具避免 FIFO 阻塞；不宣称完整 PiG 参数和行为兼容。
- Bash 与精确编辑接入既有调试、预算、动作账本和 K4 不重复副作用回退；Hybrid 仅回放。诊断和独立文件目录评测禁用 Bash。
- 配置界面和 OpenAPI 新增 Bash 字段，审批明确标记内置工具，Live 预览显示 Bash 权限。中英文 README 增加显式上游致谢，UPSTREAM 补记固定提交的行为参考清单。
- 更正 K1 完成度：最小运行/检查闭环和七类工具不等于完整 PiG、操作系统沙盒或真实业务验收。对照见 [KUN-PIG-CORE](KUN-PIG-CORE.md)。

必须一起升级 RunDesk 和 Kun。worker v15 与 v16 不混用。旧记录可读；旧检查点/未执行预览需重建，旧 K4 候选的引擎守卫将回退，应重新提炼和验证。新增可选配置默认不开放 Bash；未启用的旧配置不会自动获得宿主执行权限。go.mod/go.sum 无变更。

本版是宿主执行；现有 Codex Docker 托管没有因此支持 Kun。Linux 实执行与 Windows 交叉编译、既有 K4 回归结果见 [验证记录](KUN-VALIDATION.md)。原生 Windows、远程模型、真实浏览器布局与业务质量仍待实际环境验收。
