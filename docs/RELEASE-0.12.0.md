# RunDesk 0.12.0

新增应用镜像构建工作台。管理员上传完整构建目录 ZIP，显式启动持久化任务，查看日志、取消构建并跳转到成功生成的镜像版本。构建串行执行，支持超时和不使用缓存选项。成功结果固定为 Image ID，应用目标和已有环境不会自动变化。

这版继续沿用 0.11 的用户边界：通用助手和运行配置归管理员；成员进入获授权的 Docker 应用项目。成员和应用凭据不能访问构建 API。部署与更新仍通过既有镜像版本和环境页面操作。

参见 [构建说明](BUILDS.md)、[镜像版本](IMAGES.md)、[验证记录](VALIDATION-0.12.0.md)。升级前停止旧程序并备份数据目录，替换程序后使用原参数启动。

Linux amd64 程序与 Windows amd64 交叉编译程序随完整包提供；Docker 构建仅支持 Linux 本机 Engine。Windows 未实机验收。当前环境没有真实 Docker daemon，构建流程通过 fake Docker CLI 验证；真实基础镜像、网络依赖、Codex 认证和 MCP 服务仍需在部署主机验收。

完整包保留本版截图，源码包省略二进制及截图。历史版本文档和报告供追溯，不表示本次重新执行；早期源码恢复说明保留于 SOURCE-RECOVERY.md。
