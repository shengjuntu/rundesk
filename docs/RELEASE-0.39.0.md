# RunDesk 0.39.0 — 固定输入多案例任务集

新增不可变任务集，为后续可重复的多案例运行保存统一输入和验收规则。

- 每集 1–20 个有序案例；案例拥有唯一标识、标题、完整输入和 1–12 条文本规则。
- 管理员界面可创建、查看、分页浏览、复制为新草稿；固定内容和指纹可复核，输入空白与文字原样保留。
- 新增 3 个管理员 API 操作；保存支持幂等，列表只返回元数据，详情校验内容和版本；不依赖来源会话或项目文件。
- 案例数、标识、字符/字节数、规则重复和总文本大小均由后端校验；应用与成员无权读取或创建。
- 纳入持久化验证入口：任务集 Go/race、Node 交互、实际 HTTP 创建/读取/幂等流程。

本批只完成任务集定义层。批量执行、逐案例结果绑定、汇总评分与独立验证集隔离仍待实现，不代表完整评测或 K4 完成。Kun 0.12.0 / worker v12 / fork schema 3 保持不变，兼容现有检查点和预览；依赖没有变化。

操作与 API 见 [KUN-TASK-SETS.md](KUN-TASK-SETS.md)，最终验证结果见 [KUN-VALIDATION.md](KUN-VALIDATION.md)。
