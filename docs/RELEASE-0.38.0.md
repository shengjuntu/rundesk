# RunDesk 0.38.0 — 固定规则与评分报告

在已有的同基线分叉对照上，加入可复核的文本规则评分。管理员保存不可变规则，读取并核对两侧固定日志范围，再保存评分报告。所有操作在宿主完成，不增加模型或工具调用。

- 规则绑定完整来源基线；支持最终回复包含、不包含、完全等于指定文本，另固定要求运行成功结束。
- 评分使用同一次日志读取中的完整最终回复，不使用显示节选；晚到的执行请求/空回复/工具调用会使先前答案失效，规划与继承文本不计分。
- 逐项 pass/fail/unknown；记录缺失或超大回复保留未知，未知不按零分计算。
- 报告固定规则、比较范围、回复指纹、模式与用量摘要、分数和事件证据；保存后不随新增事件、日志删除或宿主重启改变。
- 新增 6 个管理员操作；POST 幂等，列表有界且省略正文；规则、报告和比较指纹在服务端校验。
- UI 可创建/选择规则、保存评分并重开历史报告；编辑规则或切换范围会撤销过期展示。

这是 K3 的评分基础，不代表真实业务验收、独立验证集或 K4 完成。没有自动优化、模型裁判、脚本/正则执行或候选晋升。

Kun **0.12.0 / worker v12 / fork schema 3** 保持不变，0.37 检查点和预览兼容；新增依赖为零。本次已确认实际 HTTP、界面和专项结果，最终全量 Go/vet/race 结果未取回，按部分验证交付。验证与未验收项见 [KUN-VALIDATION.md](KUN-VALIDATION.md)，使用说明见 [KUN-EVALUATION.md](KUN-EVALUATION.md)。
