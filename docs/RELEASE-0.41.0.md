# RunDesk 0.41.0

本版补齐 K4 基础闭环之后的多次采样描述性对照：同一候选的固定任务集，动态执行与快速路径逐例配对、交替先后、重复 2–5 次，最多 100 次运行。

整批一次确认后在后台顺序执行，遵守既有并发和审批。批次与私有预览原子保存，关闭界面不停止；停止只阻止后续派发，重启后不自动继续，中断/失败/删除的运行不重试。可从工作台读取进度、逐次有效输入及历史报告。

报告保留每次固定证据，汇总通过/失败/未知、快速完成/回退、模型调用、已报告 token、引擎活动加等待时间，以及匹配样本的差值。缺失不按零，报告不能作为候选启用凭据。8 个新增管理员 API 操作均有严格输入和幂等提交。

Kun 0.13.0、worker v13、fork schema 3 均保持不变；没有新增依赖。0.40 的候选、案例、独立验证报告与应用启用记录保持兼容。

本地进程和模型夹具验证机制，未开展真实业务性能研究。工作区/服务状态不重置、无随机化或显著性检验、无货币费用估计。可选学习型 JEV、真实浏览器/远程服务/生产负载仍待对应环境。
