# RunDesk 0.13.0 · 个人文件库

按 2026-10-04 确认的需求实现简单的个人文件库：自动保存上传与会话产物、「＋」选择库中附件、跨会话使用、搜索、预览、下载和删除。管理员与普通成员各自使用个人库，应用凭据不可访问。

删除会话保留库文件；删除库文件保留文字历史，附件显示已删除。个人库位于宿主机，容器通过工作区附件副本使用文件。正式产物按轮次发起人收录，避免共享会话把别人的旧文件混入个人库。

详见 [确认需求与使用说明](PERSONAL-FILES.md)、[验证记录](VALIDATION-0.13.0.md)。本版不加入知识库或共享库。升级前先备份数据目录，替换程序后使用原启动参数；旧文件不猜测个人归属、不自动批量导入。

完整包包含源码、Linux amd64 程序、Windows amd64 交叉编译程序和本版截图。Windows 和真实 Docker/Codex 组合仍需实机验证。源码包不含二进制及截图。
