# RunDesk 0.26.0 / Kun 0.6.0

本版继续完善 K2 检查界面，让控制状态、预算、MCP 与模块记录直接可读，并能追到原始事件。

- Sources：当前运行、暂停、审批、断点、控制回执和动作账本；按钮随状态更新，写入期间防重复点击，较旧响应不覆盖较新状态。
- Performance：预算卡片、活动/等待分列、模型/工具/MCP 完成记录；缺失用量按未知显示，嵌套耗时不相加。
- Application：MCP 服务与目录、审批模式和参数 Schema；固定历史审批只读，提交审批须核对当前调用。
- Layers：四模块版本、阶段、已有事实和对应事件，原始数据折叠保留。
- 共享事件跳转、稳定展开身份、折叠控制编辑器与窄屏表格滚动。

Kun 保持 0.6.0 / 协议 v6，状态格式、权限边界和恢复检查沿用上一版。是否能够继续某个检查点仍以显式检查结果为准。源码包不含二进制，使用 Go 1.25.12+ 执行 `make build`。

全量 Go 回归、静态检查、54 项 JavaScript/CJS 语法检查、两组 Node 前端回归及 Linux/Windows 构建通过。Node 回归执行了真实 DevTools 入口，但使用模拟 DOM/API，不代替浏览器与真实服务验收。K2 仍未标记全部完成；分叉、第二种 LoopPolicy 和 K4 优化未实现。

参见 [面板说明](KUN-PANELS.md)、[阶段完成度](KUN-PROGRESS.md)、[验证记录](KUN-VALIDATION.md)。
