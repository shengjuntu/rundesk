# RunDesk 0.37.0 — 工具结果假设与 Hybrid 重算

本版把“修改一条工具结果后看模型如何继续”接入可执行分叉。管理员从固定 Hybrid 预览选择录制结果，输入完整假设，核对独立固定预览后再启动。原录制保留，原工具参数、状态、顺序和预算不变，假设回放不会执行真实工具。

- 新增录制摘要 GET 和幂等假设预览 POST；现有固定 start 继续保证一份预览只拥有一个执行目标。
- worker 独立校验叠加项、原录制及新文本的指纹，实际使用时写入 `hypothetical / executed=false` 证据；未匹配仍停止。
- 编辑器明确节选、脱敏和截断，不把摘要自动当作完整原文；允许明确空字符串，保存后显示完整假设供核对。
- 检查器标记人工假设；跨会话对照分开显示真实派发、原录制回放、假设替换，并显示已使用/完整记录中未使用/未知及使用事件。
- 单个分支限一个结果，不支持 Live 替换、嵌套叠加或 K3-A 脱敏实验导入。质量评分、独立验证集和 K4 仍待实现。

升级为 **Kun 0.12.0 / worker v12 / fork schema 3**，需一起更新 RunDesk 和 Kun 并结束旧 worker。历史记录继续只读查看；0.11 及更早的检查点/预览不能跨版本执行或生成假设，需新的本版普通运行。无新增依赖。

范围见 [KUN-HYPOTHESES.md](KUN-HYPOTHESES.md)，逐阶段进度见 [KUN-PROGRESS.md](KUN-PROGRESS.md)，实际验证与未验收事项见 [KUN-VALIDATION.md](KUN-VALIDATION.md)。
