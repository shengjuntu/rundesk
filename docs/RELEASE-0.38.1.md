# RunDesk 0.38.1 — 补齐回归与保留验证结果

本批聚焦 0.38.0 未确认的最终回归，不新增业务功能。固定规则、评分语义、接口和数据格式保持兼容；Kun 0.12.0 / worker v12 / fork schema 3 不变，依赖未变化。

新增 `scripts/validate-kun.py`，可在安装 Go、Node、Python 3 与 C 编译器的环境复验。它逐项写入日志和原子更新的 `summary.json`，记录版本、源码指纹、时间、退出状态和失败信息。默认覆盖全量 Go、vet、评分/对照/假设专项 race、当前平台构建、Windows 交叉编译、JS 语法、9 组界面交互与真实宿主/worker 的本地 HTTP 模型夹具。

每次必须使用新的输出目录，避免覆盖历史结果。HTTP 检查要求同次构建成功；超时或中断会终止正在运行的检查并保存状态。进程被外部强制终止时，残留 `running` 只能视为未完成，不能作为通过证据。

最终结果与原始日志见 [KUN-VALIDATION.md](KUN-VALIDATION.md)。这些本地检查不代表真实浏览器、远程模型/MCP、Windows 运行或生产负载验收，也不代表独立验证集和 K4 完成。
