# RunDesk 0.24.0 / Kun 0.5.0

本次继续推进 K2，增加条件断点和结构化 Console，让操作前后检查与干预不依赖额外模型调用。

- 四个安全边界：模型前/后、工具前/后；支持工具/模型名、步骤、工具数、连续失败和已报告 token 条件，含一次性规则。
- 规则版本、命中计数和暂停原因持久化；运行中替换复用 revision 检查与幂等回执，检查点恢复保留规则和命中计数。
- 可选调试暂停期限；超时停止，等待不消耗活动时间预算，不能借“继续”跳过 MCP 审批。
- Console 提供七种只读查询、历史快照定位，以及固定目标和版本的控制提案。查询不会污染目标上下文。
- 配置页和 Sources 增加规则编辑器；补充 HTTP 授权、查询投影、暂停语义及恢复回归测试。

细节见 [KUN-DEBUG.md](KUN-DEBUG.md)，恢复边界见 [KUN-CHECKPOINTS.md](KUN-CHECKPOINTS.md)，验证范围见 [KUN-VALIDATION.md](KUN-VALIDATION.md)。尚无自然语言诊断、任意脚本执行或分叉。

协议 v4 → v5，两个程序须一起升级。停止旧 worker 后更换程序；旧快照可读，旧引擎检查点不能直接续跑。源码包不包含编译产物。
