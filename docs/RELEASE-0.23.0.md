# RunDesk 0.23.0 / Kun 0.4.0

本次按开发计划推进 K2：增加最近安全检查点的显式恢复，已有会话重启后可继续尚未执行的部分。它不表示 K2 全量完成。

- 状态、事件与安全检查点事务保存；在途模型/工具结果未知时阻止恢复。
- 新运行链接来源，保留已完成工具结果、上下文、模块状态及原任务消耗预算。
- 校验 worker epoch、状态版本、有效配置、技能、工作区/实例版本；MCP 重连后比对目录、重新审批。
- Sources 新增恢复检查和提交按钮；HTTP 复用既有应用授权、容量控制及幂等回执。
- 修复恢复空工具账本的初始化，并阻止前一个循环尚在清理时接收新运行。

操作和限制见 [KUN-CHECKPOINTS.md](KUN-CHECKPOINTS.md)，验证见 [KUN-VALIDATION.md](KUN-VALIDATION.md)。模型与 MCP 验证均使用本地 fixture。浏览器交互、Windows 实机、生产服务验收尚未完成。

Worker 协议由 3 升级到 4；必须同步更新两个二进制。原有数据库自动增加 checkpoints 表，旧事件/快照保留，旧版运行不支持续跑。源码包不包含编译产物。
