The complete pinned upstream repository source remains in /opt/upstreams/openmontage. Read the upstream LICENSE there. Runtime packages are installed separately from the locked dependencies declared by install.sh. The original source archive and reviewed integration sources remain in /opt/rundesk-upstream. Consult those license files before redistributing an image. No upstream code is imported into RunDesk's Go server or the independent video-build workflow.
